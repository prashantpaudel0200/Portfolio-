# Personal Portfolio Website 🚀

Welcome to my personal portfolio website.

This project is a reflection of my journey as a student developer, where I showcase my skills, projects, learning progress, and passion for creating modern web experiences.

I built this portfolio to practice and improve my frontend development skills while creating a clean, responsive, and user-friendly website.

## 🌐 Live Website

🔗  http://prashantpaudel.info.np/

## 📌 Features

- Responsive design for different screen sizes
- Modern and clean user interface
- About me section
- Skills showcase
- Projects section
- Contact section
- Smooth navigation experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub
